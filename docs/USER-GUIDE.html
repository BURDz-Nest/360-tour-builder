1. Launching the Builder

The builder is a local web app. Start a tiny local server, then open it in Chrome or Edge (required for the folder & image features).

Easiest way (Mac): Double-click scripts/launch.command in Finder. It starts the server and opens the builder automatically. Leave the little Terminal window open while you work.

Manual way (any OS):

  1. 1
    Open a terminal in the project folder and run the local server: 
    python3 -m http.server 8123
  2. 2
    In Chrome or Edge, go to: 
    http://localhost:8123/builder/index.html
Why Chrome/Edge? The builder uses the browser's File System Access API to read & write your tour folder directly. Firefox/Safari don't fully support it yet, so the folder/image buttons are hidden there.

2. Key Concepts

Tour

A self-contained folder under tours/ holding your images, the player runtime, and a tour.json. Fully portable.

Scene

One 360° photo (a single location). A tour is a list of scenes the viewer moves between.

Navigation marker

A blue waypoint pin that jumps the viewer to another scene — like a doorway.

Info marker

A teal "i" pin that opens a popup with text/details when clicked.

3. Creating a New Tour

  1. 1
    Click + New tour at the top.
  2. 2
    Type a name (e.g. "Store 1234 Frontend").
  3. 3
    When prompted, select the tours/ folder inside the project, and allow edit access.
  4. 4
    The builder creates the folder and copies the player runtime automatically. You're ready to add photos.
Already have a tour? Use Open tour folder to keep editing it, or Import tour.json to load its data (then bind its folder via the Images dialog to manage photos).

4. Adding Photos

Click Images… at the top to open the image manager. Each photo you add becomes a new scene automatically at the bottom of the list.

Way A — Let the builder do it recommended

  1. Open the Images… dialog.
  2. Drag 360 photos onto the drop zone (or click Add images).
  3. Builder copies them in, resizes to web JPEGs, makes thumbnails, and creates a scene for each.

Way B — Finder first

  1. Copy raw 360s into tours/<tour>/images/.
  2. In the builder, Open tour folder.
  3. Images… → Optimize images (resizes/converts them).
  4. Click Add all as scenes.
Auto-optimization: Photos are downscaled to a max of 4096px wide and saved as JPEG. This keeps tours fast and prevents black screens on locked-down work laptops (which often cap image sizes). Only the web version is stored — keep your originals elsewhere.

5. Managing Scenes

  • Select a scene by clicking its name in the left list — its 360 loads in the center preview.
  • Reorder by dragging the ☰ grip handle (or use the Up/Down buttons).
  • Rename via the scene name field. Add a caption for a label shown in the player.
  • Set the start scene with Set as start — this is where the tour opens.
  • Delete a scene with the red Delete scene button.
  • Swap a scene's photo: select the scene, open Images…, and click a thumbnail to reassign it.

6. Adding Markers (Hotspots)

Markers are the interactive dots in your tour. Two kinds, both added the same way — the newest appears at the top of the list and is auto-selected.

To place a marker:

  1. 1
    Select the scene you want to add it to.
  2. 2
    Click + Navigation or + Info.
  3. 3
    Click the spot in the 360 preview where the marker should go (e.g. a doorway for navigation).
  4. 4
    Fill in the marker's card:
    • Navigation: pick the target scene it jumps to, plus a label.
    • Info: add a title and body text for the popup.
Tip: To move a marker, re-select it and click a new spot in the preview. Link scenes in any direction — there's no forced order.

7. Saved Views & Options

  • Saved view per scene: drag/zoom the preview to the angle you want, then capture it. The player opens each scene facing that direction, and navigation fades in already facing it (no spinning).
  • Show thumbnails toggle (Tour details): when on, hovering a navigation pin shows a snapshot preview of the target scene. Turn it off for a cleaner look — pins then show just the scene title.

8. Saving & Previewing

Preview in player

Opens your tour exactly as visitors will see it, in a new tab. Use it constantly.

Save tour

Writes tour.json straight into your tour folder — no dialog. Save often!

Note: If the builder's code is updated, hard-refresh (Cmd+Shift+R) so the browser loads the latest version.

9. Sharing Your Tour

A tour folder is fully self-contained — copy it anywhere and it works. Common options:

  • Send the folder: zip tours/<your-tour>/ and share it. The recipient opens player.html.
  • Host it: upload the tour folder to any static web host or internal site. See docs/DEPLOY.md for GitHub Pages / Azure Blob steps.
Before sharing: make sure photos contain no sensitive/PII content. See docs/SECURITY.md for data-handling guidance.

10. Troubleshooting

The folder/Images buttons are missing

You're not in Chrome or Edge. Switch browsers — the File System features need them.

The 360 image shows black

The image is likely too large for your GPU. Open Images… and click Optimize images to resize everything to a safe 4096px.

Hover previews show a broken image

Thumbnails weren't generated yet. Open the tour, then hit Preview or Save once — the builder auto-generates any missing thumbnails.

My latest change isn't showing

Hard-refresh with Cmd+Shift+R (or Ctrl+Shift+R on Windows) to clear cached files.

The server won't start / port in use

Something is already using port 8123. Close the old Terminal window, or run the server on another port and adjust the URL.
