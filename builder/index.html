    Help & publishing

    Quick start

    1. New project → name it → pick the tours/ folder.
    2. Open Images… and drag in your 360 photos — each becomes a scene (auto-resized using your Image quality setting; default is Balanced 4096px).
    3. Add Navigation / Info hotspots by clicking in the preview.
    4. Save tour, then Preview in player.

    Publishing to GitHub — what you’ll need

    • A GitHub account and a repository
    • Push your project folder to the repo
    • Turn on GitHub Pages (Settings → Pages → deploy from main, root /)
    • Your live link:
      https://<user>.github.io/<repo>/tours/<tour>/player.html

    Using Azure for images (big tours) — what you’ll need

    • An Azure Storage account + a Blob container
    • CORS enabled on the container for your Pages domain (the #1 gotcha — without it, images load black)
    • Public read access or a SAS token
    • Upload your images/ files, then reference them by their Azure URL

    Tip: small/medium tours are simplest committed straight to GitHub. Reach for Azure when a tour has lots of high-res photos.
