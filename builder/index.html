    Help & publishing

    The big idea

    Spherio Studio turns your 360° photos into a clickable walk-through tour — no coding. Each tour is just a folder on your computer that holds the photos and a tour.json file describing the scenes and hotspots. “Opening a project” means picking that folder; “saving” writes the tour.json back into it.

    A scene = one 360° photo. A hotspot = a clickable thing on a photo (a doorway that jumps to another scene, or an info point that pops up details). An area/group = an optional folder-within-your-tour for organizing lots of scenes.

    Get going in 4 steps

    1. Click + New tour (top-left), name it, and pick where to save the folder. Already have a tour? Use Open tour folder.
    2. Click Images… and drag your 360 photos in — each photo becomes a scene automatically.
    3. Pick a scene on the left, set its opening view, then open the Hotspots tab to add navigation arrows and info points.
    4. Click Save tour, then Preview in player to see the real thing.

    Images: adding, sizing & compressing

    Two ways to add photos

    • Drag & drop (easiest): open Images… and drop your 360s onto the box (or click Add images…). Each one is copied into the tour's images/ folder and added as a new scene.
    • Already in the folder? If you copied photos into images/ yourself (Finder/Explorer), click Add all as scenes — this uses them as-is with no re-encoding.

    Quality & file size (the important part)

    • Set it in Tour settings → Image quality. It applies to photos you add or optimize from then on.
    • Original (default) — keeps your camera's full resolution. Sharpest text/signage, biggest files. Best for training detail.
    • Maximum 8192 / High 6144 / Balanced 4096 / Web 4096 — each downscales to that width for smaller, faster-loading files.
    • Optimize images re-encodes everything already in the folder at the current quality setting — handy for shrinking a heavy tour before publishing.

    One-way street: optimizing can only shrink or compress — it can never add resolution or sharpness back. Always keep your original photos somewhere safe so you can re-import at a higher quality if needed. (Thumbnails for the nav pop-ups are made for you automatically.)

    To set or swap a single scene's photo, open Images… — the “Panorama image” field in Scene settings is read-only on purpose.

    Working with scenes

    • Select a scene on the left to edit it.
    • Opening view: rotate/zoom the preview to the angle you want, then Capture current view. Visitors start facing that way.
    • Name and optional Caption live in Scene settings.
    • Set as start makes it the first scene. Duplicate scene copies it (with hotspots). Delete scene removes it.

    Areas (groups) & moving scenes

    • Big tour? Click + New group to make an area (players get an Areas menu to jump around).
    • Move / reorder: just drag a scene in the list — drop it on another scene or into a group's space. This works across groups, so that's how you move a scene from one area to another.
    • Each group's menu lets you rename, recolor, pick its entry scene, or delete it.
    • Scenes not in any group simply stay “ungrouped” at the top.

    Hotspots: navigation, info icons & info zones

    Pick a scene, open the Hotspots tab, then choose Navigation or Info.

    • Navigation (+ Navigation): click in the preview to drop it, then choose the target scene and an icon. These are the arrows/pins that move visitors between scenes.
    • Info icon (+ Info icon): a small glyph you click to open a pop-up. Choose an icon from the library and write the description.
    • Info zone (+ Info zone): a transparent box over a whole object/area. After adding it, drag its corner dots in the preview to fit the shape. The magnifier toggle helps mobile users spot zones.
    • Move a pin: click it to select, then drag it in the preview. Reuse work: Copy hotspots… pulls all hotspots from another scene.

    Descriptions accept HTML — add bold text, links, images, even video. Ready-made snippets live in the templates/ folder next to this app.

    Guided experience (optional)

    • Turn it on in Tour settings → Guided experience.
    • It hides the nav arrows and goes linear: the learner must open every required info hotspot in a scene before a Continue prompt appears. Mark hotspots “required” in the Hotspots panel.
    • Options: a welcome screen, a completion message, and Allow scene skipping (adds prev/next arrows so a facilitator can jump ahead when short on time).

    Save, preview & re-open

    • Save tour writes tour.json into the folder. Save often!
    • Preview in player opens the real viewer with your current work.
    • Reopen anytime with Open tour folder or from “Recent projects” on the welcome screen.
    • Only have a tour.json file? Use Import tour.json.

    Publish it (share a link)

    GitHub Pages — simplest for most tours

    1. Push your tour folder to a GitHub repository.
    2. Turn on GitHub Pages: repo Settings → Pages → deploy from main, root /.
    3. Share the link to …/player.html, e.g.
      https://<user>.github.io/<repo>/<tour>/player.html

    Azure Blob — only for very large, high-res tours

    • Storage account + a Blob container, with CORS enabled for your site's domain (the #1 gotcha — without it images load black).
    • Public read (or a SAS token), upload your images/, then point the scenes at their Azure URLs.

    Handy tips & fixes

    • Images look black in a published tour? You're probably opening player.html by double-clicking it (a file:// address). Serve it over http(s):// instead — browsers block local files from WebGL.
    • Keep your originals. Optimizing is one-way; you can't un-shrink a photo.
    • Changes not showing? Hard-refresh the page (Cmd/Ctrl+Shift+R).
    • Easier on the eyes: the moon/sun button (top-right) toggles dark mode.
